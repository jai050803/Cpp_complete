# Basics of C++

This folder contains 10 C++ programs covering fundamental concepts:

## 1. Data Types
- **int, float, double, char, bool**: Used to store numbers, characters, and logical values.
- **Edge Cases**: Overflow/underflow, precision loss (float/double), char encoding.
- **Usage**: Choose based on required range and precision. Use `int` for counting, `double` for scientific calculations, `char` for single characters, `bool` for logical flags.

## 2. Input and Output
- **cin/cout**: Standard input/output for numbers, arrays, and strings.
- **Edge Cases**: Buffer issues, reading spaces in strings (use `getline` for full lines), invalid input types.
- **Usage**: Use `cin` for simple input, `getline` for strings with spaces. Always validate input.

## 3. Conditional Statements
- **if, else if, else**: Used for decision making.
- **Edge Cases**: Nested conditions, unreachable code, type conversions in comparisons.
- **Usage**: Use for branching logic, input validation, error handling.

## 4. Switch Case
- **switch**: Multi-way branching for discrete values.
- **Edge Cases**: Missing `break` (fall-through), default case, non-integer types.
- **Usage**: Use for menu selection, day mapping, enums.

## 5. Number System Conversion
- **Decimal to Binary**: Bitwise operations for conversion.
- **Edge Cases**: Negative numbers, leading zeros, large values.
- **Usage**: Use for low-level programming, bit manipulation, competitive coding.

## 6. Prime Number
- **Prime Check**: Loop and modulo for primality.
- **Edge Cases**: Numbers ≤ 1, large numbers, performance.
- **Usage**: Use for mathematical algorithms, cryptography.

## 7. Factorial
- **Factorial Calculation**: Loop multiplication.
- **Edge Cases**: Large numbers (overflow), negative input.
- **Usage**: Use for combinatorics, probability, recursion practice.

## 8. Counting Set Bits
- **Bit Counting**: Bitwise AND and shift.
- **Edge Cases**: Negative numbers, zero input.
- **Usage**: Use for bit manipulation, optimization, hardware programming.

## 9. OOPs - Class and Object
- **Class/Object**: Encapsulation, data abstraction.
- **Edge Cases**: Uninitialized members, access specifiers.
- **Usage**: Use for modeling real-world entities, code organization.

## 10. OOPs - Inheritance
- **Inheritance**: Code reuse, hierarchy.
- **Edge Cases**: Method overriding, access control, multiple inheritance.
- **Usage**: Use for extending functionality, polymorphism.

---

**Best Practices:**
- Always validate input.
- Handle edge cases (invalid, extreme values).
- Use appropriate data types for efficiency and correctness.
- Structure code for readability and maintainability.
